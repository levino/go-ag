# Flyer / Aushang

Ein fertiger **DIN-A4-Flyer** zum Ausdrucken, Aushängen oder Auslegen – zum
Beispiel beim Sommerfest. Er lädt zum Mitspielen in die Go-AG ein und enthält
einen QR-Code, der direkt auf diese Website führt.
